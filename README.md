# Dylan Waweru's Portfolio

A simple website that tells people about me and my work.

## Live website

[Open my portfolio](https://dylanwaweru000-cmyk.github.io/dylanwaweru-portfolio/)

The site is not online yet. This link will work after I publish it with GitHub Pages.

## Features

- Links to each part of the page
- Testimonials and projects added with JavaScript
- My email and GitHub links
- A layout that works on phones and computers

## Technologies

- HTML makes the page
- CSS adds colors and makes the page fit small screens
- JavaScript adds the testimonials and projects

## Run it on your computer

1. Open the project folder.
2. Open `index.html` in a web browser.

## What I learned

I learned how HTML, CSS, and JavaScript work together to make a website. I also learned how JavaScript can add content to a page.
